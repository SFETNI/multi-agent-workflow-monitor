# Audit claim limits

The scanner detects defined path, identifier, credential, runtime-artifact, archive, URL, and metadata classes. It cannot prove arbitrary prose safe, identify every secret format, or replace human image inspection. A clean audit applies only to the exact hashed bytes and the supplied external denylist.

The public receipt reports category/count/status. Keep denylist contents, matching values, source locations outside the candidate, and raw tool output private.
