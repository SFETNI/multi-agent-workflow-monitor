# Public replay

Serve static/ on loopback. All eight views work offline; the replay is fictional example data and does not connect to live sources.

public_snapshot.json is the normalized v2 input. accepted_snapshot.json is the deterministic presentation fixture. build_demo.py validates and projects the data through the same renderer used by the local application.

Canonical media includes the overall GIF, 1920x1080 and 1440x1000 monitor views, the usage/API-value view, and the Workflow & Trace view. No private comparison images are distributed.
