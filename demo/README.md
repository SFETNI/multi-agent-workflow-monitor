# Public replay

Open static/index.html or serve static/ on loopback. All seven views work. The replay is frozen example data; it does not connect to live sources.

public_snapshot.json is the normalized input. accepted_snapshot.json is the public presentation fixture from the frozen visual authority. config/public_snapshot.json in the repository mirrors the normalized demo for the quick-start configuration. build_demo.py validates and projects the data through the same renderer used by the local application.

Media contains the accepted 1920x1080 and 1440x1000 screenshots and 104-frame, 13-second GIF. No private comparison images are distributed.
